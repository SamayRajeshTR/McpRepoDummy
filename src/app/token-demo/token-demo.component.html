How to implement Saffron design tokens

  1. Identify Saffron tabs component tokens using the tokens table .
  2. Reference the Saffron tabs component Figma design to see where tokens are applied.
  3. Identify how styling is applied to the FAST tabs component, since this is a web-component, look for existing css-variables, css parts , or slots to help identify what you can actually style. Web components styles by default are encapsulated, this may affect your ability to override styles.
  4. Import Saffron @saffron/core-styles package to get Saffron design tokens.
  5. Implement the design tokens into the FAST tabs component via css stylesheet.

    In this case, we are scoping our tokens to the `saffron` class applied to the second tabs example.
