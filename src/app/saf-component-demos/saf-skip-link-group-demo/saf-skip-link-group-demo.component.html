Skip Link Group

Multiple skip links are grouped within a container

Grouped skip links are to be set inside of a skip link container that carries a dashed border and a white background.

When a group of skipped links are placed on a narrower screen (around 767px) the skip links should start wrapping to a vertical orientation.

There is a change of styles related to the grouped component that can be found in the component file.
